Este projeto foi desenvolvido no âmbito do Programa de Extensão do IFSertãoPE, 
com o objetivo de ensinar lógica de programação de forma prática e acessível. 
![Captura de tela 2024-12-11 201022](https://github.com/user-attachments/assets/7256b8a5-ce0f-4719-a99d-60497f4ec388)

Além disso, busca fortalecer o aprendizado dos conceitos matemáticos, 
oferecendo uma abordagem integrada que conecta a programação à matemática. 
![Captura de tela 2024-12-11 201735](https://github.com/user-attachments/assets/66316420-c93f-4f70-ae60-be372a816ca9)


Dessa maneira, os participantes podem desenvolver tanto habilidades técnicas quanto um entendimento mais profundo de alguns fundamentos matemáticos.
![Captura de tela 2024-12-11 201216](https://github.com/user-attachments/assets/1e07e886-6ea9-4577-a382-b7db671e31fd)

Reajustamos nosso projeto para oferecer a melhor experiência e dinamismo aos nossos seguidores! 
Agora, ele está totalmente adaptado para todos os dispositivos, garantindo acesso fácil e confortável, seja no celular, tablet ou computador.
Além disso, adicionamos vídeos tutoriais exclusivos utilizando o Scratch, tornando o aprendizado ainda mais interativo e visual. 
Com essas melhorias, estamos conectando a matemática e a programação de forma prática e envolvente.
