se divertindo

Este projeto foi desenvolvido no âmbito do Programa de Extensão do IFSertãoPE, com o objetivo de ensinar lógica de programação de forma prática e acessível. Além disso, busca fortalecer o aprendizado dos conceitos matemáticos, oferecendo uma abordagem integrada que conecta a programação à matemática. Dessa maneira, os participantes podem desenvolver tanto habilidades técnicas quanto um entendimento mais profundo de alguns fundamentos matemáticos.
